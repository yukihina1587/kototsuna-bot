# TTS 読み上げルール

ことつな！の VOICEVOX 読み上げ（TTS）機能において、**何が読み上げられるか・読み上げられないか**を整理したリファレンスページです。

---

## 読み上げられるもの

| # | 内容 | 条件 |
|---|------|------|
| A | 通常チャット（翻訳なし） | TTS スイッチが ON |
| B | 通常チャット（翻訳あり）| TTS スイッチが ON ／ **翻訳後テキスト（日本語）を優先**して読み上げる。翻訳結果がない場合は原文を読む |
| C | 参加キーワード検出メッセージ | TTS スイッチが ON ／「○○さんが参加希望登録しました。」と読む |
| D | フォローイベント | **TTS スイッチに関係なく常に読み上げる** |
| E | サブスクリプションイベント | **常に読み上げる** |
| F | ギフトサブイベント | **常に読み上げる** |
| G | Bits（チア）イベント | **常に読み上げる** |
| H | バッジ獲得イベント | **常に読み上げる** |
| I | `!translate` コマンドの翻訳結果 | TTS スイッチが ON ／ 翻訳後テキストのみ読む（原文は読まない） |

> **D〜H（特別イベント）について:** フォロー・サブスク・Bits などの通知は、TTS スイッチの ON/OFF に関係なく**必ず読み上げます**。重要な通知を見逃さないための仕様です。

---

## 読み上げられないもの（意図的スキップ）

| # | 内容 | 理由 |
|---|------|------|
| 1 | BOT 自身が送信したメッセージ | ゼロ幅スペース（`\u200B`）で識別し、自己ループを防ぐ |
| 2 | 翻訳フィルターにかかったコメント | フィルター設定でスキップ対象になったコメント |
| 3 | 音声認識（STT）の文字起こし翻訳 | STT 結果は「声→翻訳チャット」機能でチャットに投稿され、通常コメントとして処理される |
| 4 | OBS シーンルールで TTS ミュート中のすべてのコメント | シーン切り替えによる自動ミュート中 |
| 5 | BOT フィルターにかかったユーザーのコメント | 既知の BOT アカウントと判定されたユーザー |
| 6 | `!translate` コマンド以外のコマンド応答 | `!help`・`!lang`・`!tts` などのコマンド返信は読まない |

---

## 設定で変えられること

| 設定項目 | 場所 | 効果 |
|---------|------|------|
| TTS スイッチ | サイドバー | 通常コメント（A〜C・I）の ON/OFF。特別イベント（D〜H）は影響しない |
| 名前読み上げ（名前を含める） | TTS 設定 | コメント読み上げ時に「○○さん、」と名前を前置きするかどうか |
| 話者（VOICEVOX キャラクター） | TTS 設定 | 読み上げ音声のキャラクターを変更 |
| OBS シーンミュートルール | OBS 連携設定 | 特定 OBS シーンに切り替えたとき TTS を自動 OFF にする |
| 翻訳フィルター | フィルター設定 | 特定ワード・パターンを含むコメントを TTS からスキップ |
| BOT フィルター | BOT フィルター設定 | 既知 BOT アカウントのコメントを TTS からスキップ |
| `!voice` コマンド | チャット | 視聴者が自分の発言専用話者を変更できる（モデレーターが許可した場合） |

---

## 読み上げ優先ロジック（B の詳細）

```
チャットコメントが届く
  ↓
翻訳が有効か？
  ├─ NO  → 原文をそのまま読み上げる
  └─ YES → 翻訳後テキスト（日本語）があるか？
              ├─ YES → 翻訳後テキストを読み上げる
              └─ NO  → 原文を読み上げる
```
