# パフォーマンス最適化

長時間稼働（数時間〜）でのメモリリーク・CPU過負荷を防止するための仕組みをまとめています。

## メモリ管理

### 自動制限

各データ構造に上限が設けられており、古いデータは自動的に削除されます。

| データ | 上限 | 設定キー | 備考 |
|-------|------|---------|------|
| ログ履歴 | 1000件 | `chat_log_history_limit` | `config.json`で変更可 |
| チャット履歴 | 200件 | — | 固定 |
| 参加者リスト | 1000人 | `participant_limit` | `config.json`で変更可 |
| 翻訳キャッシュ | 500件 / TTL 10分 | — | 固定 |

### 自動再起動

メモリ使用量が閾値を超えた場合、ダイアログで再起動を提案します。

```json
{
  "auto_restart_enabled": true,
  "auto_restart_threshold_mb": 1000
}
```

- デフォルトは無効（`false`）
- 再起動前に設定は自動保存されます
- BOTの接続は安全に切断されます

## 翻訳処理の効率化

### セッション永続化

aiohttp.ClientSessionを再利用し、リクエストごとのTCPハンドシェイク・SSL接続オーバーヘッドを削減します。

### バッチ処理

短時間に複数のチャットメッセージが来た場合、まとめて処理します。

- **待機時間**: 100ms（最初のメッセージ到着から）
- **最大バッチサイズ**: 5件
- **キャッシュ済み**: 即座に返却（バッチ対象外）

### 翻訳キャッシュ

LRUキャッシュ（TTL 10分、最大500件）により、同じテキストの再翻訳を防止します。

### 統計表示

ステータスバーに翻訳統計が表示されます:
- リクエスト数 / キャッシュヒット数 / フィルター数
- 平均API応答時間（ms）

## GUI差分更新

### DifferentialListManager

参加者リストなどの定期更新（3秒間隔）を最適化します。

| 従来の方式 | 新しい方式 |
|-----------|-----------|
| 全ウィジェットをdestroy → 全再作成 | 追加/削除があった分だけ操作 |
| 20人の場合: 毎回20個のdestroy + 20個のcreate | 変更なし: 操作0回 |

### 対象

- メイン画面の参加者リスト
- 参加者タブの参加者リスト
- 右パネルの参加者リスト

## リソース監視

### 非ブロッキング監視

CPU統計はバックグラウンドスレッドで収集され、メインスレッド（GUI）をブロックしません。

| 従来 | 改善後 |
|------|-------|
| `cpu_percent(interval=0.1)` × 2回 | バックグラウンドで2秒間隔収集 |
| メインスレッドを0.2秒ブロック | 非ブロッキング（キャッシュ読み取り） |

### 監視項目

- プロセスメモリ使用量（MB / %）
- プロセスCPU使用率（%）
- システムCPU使用率（%）
- アクティブスレッド数
- システムメモリ（空き容量 / 使用率）

## パフォーマンス計測

### PerformanceMetrics

主要な処理の実行時間を計測し、統計を提供します。

```python
from src.performance_logger import get_perf

perf = get_perf()

# コンテキストマネージャーで計測
with perf.measure("my_operation"):
    do_something()

# 統計を取得
stats = perf.get_stats("my_operation")
# → {"count": 100, "min": 5.2, "max": 150.3, "avg": 23.4, "p95": 45.6, "p99": 120.1}
```

### 計測対象

| 名前 | 対象 |
|-----|------|
| `deepl_api` | DeepL API呼び出し |

## プロファイリング

### CPUプロファイリング

```bash
python scripts/profile_app.py cpu
```

- cProfileでアプリケーション全体を計測
- 終了後に上位30関数を表示
- `profile_output.prof`ファイルに詳細を保存
- `snakeviz`で可視化可能

### メモリプロファイリング

```bash
python scripts/profile_app.py memory
```

各種メモリプロファイリングツールの使い方を案内します:
- `memory_profiler`: 行単位のメモリ使用量
- `tracemalloc`: Python標準のメモリ追跡
- `objgraph`: オブジェクト参照の可視化
