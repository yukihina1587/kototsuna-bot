# OBS ブラウザソースの設定方法

ことつな！のチャット翻訳をOBSの配信画面に表示する方法を説明します。

## 手順

### 1. ことつな！を起動

アプリを起動すると、オーバーレイサーバーが自動的に開始されます。
サイドバーの「OBS連携」セクションに表示されるURLを使用します。

### 2. OBSでブラウザソースを追加

1. OBSの **「ソース」** パネルで **「＋」** ボタンをクリック
2. **「ブラウザ」** を選択
3. 名前を入力して **「OK」**

### 3. URLを設定

プロパティ画面で以下を設定します：

| 項目 | 値 |
|------|-----|
| **URL** | `http://localhost:8080/chat`（アプリに表示されたURL） |
| **幅** | `400`（推奨） |
| **高さ** | `800`（推奨） |
| **カスタムCSS** | 下記参照 |

#### カスタムCSS（推奨）

背景を透明にするには、以下をカスタムCSSに貼り付けてください：

```css
body { background-color: transparent; }
```

### 4. 完了

**「OK」** をクリックすれば設定完了です。
チャットが来ると自動的に表示が更新されます（約1.2秒間隔）。

## ポート番号について

デフォルトではポート `8080` を使用しますが、他のアプリが使用中の場合は自動的に別のポート（8081, 8082...）が選択されます。

アプリのサイドバー「OBS連携」セクションに表示されるURLが正しいポート番号を含んでいるので、必ずそちらを使用してください。

## 表示されない場合

- アプリが起動していることを確認
- ブラウザソースを右クリック → **「キャッシュをリフレッシュ」**
- URLのポート番号がアプリに表示されたものと一致しているか確認
- 詳しくは [トラブルシューティング](Troubleshooting) を参照

## スタイルのカスタマイズ

チャットの見た目は `custom.css` ファイルで変更できます。
HTMLの出力先フォルダ（デフォルト: `%APPDATA%\Kototsuna\templates\chat\`）に `custom.css` を配置すると自動的に読み込まれます。
