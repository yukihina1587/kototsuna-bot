# OBS 連携ガイド

ことつな！は OBS Studio と以下の方法で連携できます。

| 連携方法 | 用途 |
|---------|------|
| [ブラウザソース（チャット）](#ブラウザソースチャット表示) | チャット翻訳ログをオーバーレイ表示 |
| [ブラウザソース（字幕）](#ブラウザソース字幕オーバーレイ) | 音声翻訳の字幕をリアルタイム表示 |
| [OBS WebSocket 連携](#obs-websocket-連携) | 配信状態やシーン変更に応じてBOTを自動制御 |

---

## ブラウザソース（チャット表示）

### 1. ことつな！を起動

アプリを起動するとオーバーレイサーバーが自動的に開始されます。
サイドバーの「OBS連携」セクションに表示される URL を使用してください。

### 2. チャットHTML出力を有効にする

1. 右パネルの **「設定」** タブを開く
2. **「チャットHTML出力」** をオンにする
3. 出力先のフォルダを指定（初回のみ）

### 3. OBSでブラウザソースを追加

1. OBS の **「ソース」** パネルで **「＋」** → **「ブラウザ」** をクリック
2. 名前を入力して **「OK」**
3. 以下を設定：

| 項目 | 値 |
|------|-----|
| **URL** | `http://localhost:8080/chat` |
| **幅** | `400`（推奨） |
| **高さ** | `800`（推奨） |
| **カスタムCSS** | 下記参照 |

#### カスタムCSS（推奨）

```css
body { background-color: transparent; }
```

4. **「OK」** をクリックで完了。チャットが届くたびに自動更新されます。

### ポート番号について

デフォルトは `8080` ですが、使用中の場合は `8081`, `8082`... と自動的に空きポートを探します。
サイドバーの「OBS連携」セクションに表示された URL をそのまま使用してください。

## ブラウザソース（字幕オーバーレイ）

マイク入力から翻訳した内容をリアルタイムで字幕表示できます。

### 1. 字幕機能を有効にする

1. 右パネルの **「設定」** タブを開く
2. **「字幕オーバーレイ」** セクションで **「有効」** をオンにする
3. フォント・サイズ・色・表示時間などを好みに合わせて調整

### 2. OBSでブラウザソースを追加

| 項目 | 値 |
|------|-----|
| **URL** | `http://localhost:8080/subtitle` |
| **幅** | `1280`（推奨） |
| **高さ** | `200`（推奨） |
| **カスタムCSS** | `body { background-color: transparent; }` |

### 字幕の設定項目

| 設定キー | 説明 | デフォルト |
|---------|------|-----------|
| `subtitle_enabled` | 字幕オーバーレイの有効/無効 | `false` |
| `subtitle_show_original` | 原文を表示するか | `true` |
| `subtitle_show_translated` | 翻訳文を表示するか | `true` |
| `subtitle_show_speaker` | 話者名を表示するか | `false` |
| `subtitle_show_timestamp` | タイムスタンプを表示するか | `false` |
| `subtitle_font_family` | フォント名 | `"Noto Sans JP"` |
| `subtitle_font_size` | フォントサイズ（8〜200） | `32` |
| `subtitle_text_color` | 文字色（16進数） | `"#FFFFFF"` |
| `subtitle_stroke_color` | 縁取り色（16進数） | `"#000000"` |
| `subtitle_stroke_width` | 縁取り幅（0〜20） | `3` |
| `subtitle_display_seconds` | 表示持続時間（秒、1.0〜60.0） | `5.0` |
| `subtitle_max_lines` | 最大行数（1〜10） | `3` |

## OBS WebSocket 連携

OBS WebSocket を使用して、配信状態やシーン変更を自動的に検知し、BOT を制御できます。

### 必要なもの

- **OBS Studio 28.0 以降**（obs-websocket が標準搭載）
- Python パッケージ: `obsws-python`（要インストール）

```bash
pip install obsws-python
```

> **注意**: `obsws-python` が未インストールの場合、OBS WebSocket 連携は自動的に無効になります。他の機能への影響はありません。

### OBS 側の設定

1. OBS のメニューから **「ツール」** → **「WebSocketサーバー設定」** を開く
2. **「WebSocketサーバーを有効にする」** にチェック
3. 認証が必要な場合は **パスワードを設定** する
4. ポート番号（デフォルト: `4455`）を確認して **「OK」**

### ことつな！側の設定

1. 右パネルの **「設定」** タブを開く
2. **「OBS WebSocket」** セクションで以下を入力：

| 項目 | 説明 | デフォルト |
|------|------|-----------|
| **有効** | OBS WebSocket 連携のオン/オフ | オフ |
| **ホスト** | OBS が動作している PC（同じ PC なら `localhost`） | `127.0.0.1` |
| **ポート** | OBS WebSocket のポート番号 | `4455` |
| **パスワード** | OBS WebSocket のパスワード（設定した場合のみ） | 空白 |
| **ポーリング間隔** | 状態確認の間隔（秒、0.2〜10.0） | `1.0` |

### 自動制御機能

| 機能 | 説明 | 設定キー |
|------|------|---------|
| **配信開始で BOT 自動起動** | 配信を開始すると自動的に BOT が起動します | `obs_auto_start_bot` |
| **配信終了で BOT 自動停止** | 配信を終了すると自動的に BOT が停止します | `obs_auto_stop_bot` |

> **自動制御を有効にする条件**: `obs_auto_control_enabled` が `true` かつ `obs_enabled` が `true` である必要があります。

### シーンルール

シーンを切り替えたときに TTS ミュートやソースの表示/非表示を自動制御できます。

#### 設定例（config.json）

```json
"obs_scene_rules": [
  {
    "scene": "休憩",
    "tts_mute": true,
    "show_sources": ["BreakCard"],
    "hide_sources": ["AlertOverlay"]
  },
  {
    "scene": "ゲーム",
    "tts_mute": false,
    "show_sources": ["AlertOverlay"],
    "hide_sources": ["BreakCard"]
  }
]
```

| フィールド | 型 | 説明 |
|-----------|-----|------|
| `scene` | string | OBS のシーン名（大文字小文字を区別しない） |
| `tts_mute` | boolean | `true` で TTS をミュート、`false` で解除 |
| `show_sources` | string[] | 表示するソース名の配列 |
| `hide_sources` | string[] | 非表示にするソース名の配列 |

#### 動作フロー

```
OBS でシーン変更
      ↓
シーン名がルールと一致するか確認（大文字小文字無視）
      ↓
一致したルールを適用
  ├─ tts_mute: true  → TTS を自動ミュート
  ├─ tts_mute: false → TTS のミュートを解除
  ├─ show_sources    → 指定ソースを表示
  └─ hide_sources    → 指定ソースを非表示
```

### 接続方式

ことつな！は以下の優先順位で OBS に接続します：

1. **EventClient**（WebSocket イベント購読）: リアルタイムでシーン変更・配信状態変化を検知
2. **フォールバック（ポーリング）**: EventClient に失敗した場合、設定した間隔でポーリング

## トラブルシューティング

### ブラウザソースが表示されない

1. ことつな！が起動していることを確認
2. ブラウザソースを右クリック → **「キャッシュをリフレッシュ」**
3. URL のポート番号がサイドバーに表示されたものと一致しているか確認

### OBS WebSocket に接続できない

1. OBS の「ツール」→「WebSocketサーバー設定」で **「有効」にチェックが入っているか** 確認
2. ポート番号・パスワードがことつな！の設定と一致しているか確認
3. `obsws-python` がインストールされているか確認：
   ```bash
   pip show obsws-python
   ```
4. ファイアウォールでポート `4455` が許可されているか確認

### 配信開始しても BOT が自動起動しない

1. `obs_enabled` が `true` になっているか確認
2. `obs_auto_control_enabled` と `obs_auto_start_bot` が `true` か確認
3. ことつな！のログ（DEBUG レベル）で `[OBS]` の行を確認

詳しくは [トラブルシューティング](Troubleshooting) を参照してください。
