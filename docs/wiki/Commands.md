# コマンドリファレンス

Twitchチャットで `!` プレフィックスを付けて送信することでコマンドが使用できます。

---

## 権限レベル

| レベル | 値 | 対象 |
|-------|---|------|
| 全員 | 0 | すべての視聴者 |
| サブスク | 1 | サブスクライバー |
| VIP | 2 | VIPユーザー |
| モデレーター | 3 | チャンネルモデレーター |
| 配信者 | 4 | チャンネルオーナー |

上位権限は下位権限を包含します。

---

## 全ユーザー向けコマンド

### `!help`
使用可能なコマンド一覧をチャットに表示します（カスタムコマンド含む）。

---

### `!translate <テキスト>`
指定したテキストをその場で翻訳してチャットに返信します。現在の翻訳モードが適用されます。

```
!translate Hello, world!
→ [翻訳] こんにちは、世界！
```

---

### `!lang`
現在設定されている翻訳モード（`自動` / `英→日` / `日→英`）を表示します。

---

### `!visits`
自分の視聴回数を表示します。

---

### `!leave`
自分を待機リストから削除します。

---

### `!voice list`
利用可能なVOICEVOXボイスの一覧を表示します（最大10件、設定で許可されたもの）。

---

### `!myvoice`
現在自分に設定されているボイスを確認します。

### `!myvoice <ボイスID>`
自分のボイスを指定のIDに変更します。`voice_assign_mode` が `self_service` のとき、または MOD+ の場合に使用可能です。

### `!myvoice reset`
自分のボイスをデフォルトに戻します。

---

## モデレーター以上向けコマンド

### `!tts on` / `!tts off`
チャットの読み上げ（TTS）を有効/無効に切り替えます。引数なしで現在の状態を確認できます。

---

### `!translation on` / `!translation off`
**チャット翻訳**を有効/無効に切り替えます。引数なしで現在の状態を確認できます。

```
!translation on   → チャット翻訳を有効にしました
!translation off  → チャット翻訳を無効にしました
!translation      → チャット翻訳: ON (使い方: !translation on/off)
```

---

### `!voicechat on` / `!voicechat off`
**声→翻訳チャット**（マイク入力の音声認識・翻訳・チャット送信）を有効/無効に切り替えます。

```
!voicechat on   → 声→翻訳チャットを有効にしました
!voicechat off  → 声→翻訳チャットを無効にしました
!voicechat      → 声→翻訳チャット: OFF (使い方: !voicechat on/off)
```

---

### `!dict add <単語> <読み>`
TTS読み上げ辞書に単語を登録します。

```
!dict add 草 くさ
→ 辞書に追加しました: 草 → くさ
```

### `!dict list`
TTS辞書の登録一覧を表示します（最大10件プレビュー）。

### `!dict remove <単語>`
TTS辞書から単語を削除します。

---

### `!voice set @<ユーザー名> <ボイスID>`
指定ユーザーにVOICEVOXボイスを割り当てます。

```
!voice set @username 14
→ @username のボイスを 冥鳴ひまり / ノーマル (ID:14) に設定しました
```

### `!voice remove @<ユーザー名>`
ユーザーへのボイス割り当てを解除してデフォルトに戻します。

### `!voice check @<ユーザー名>`
指定ユーザーの現在のボイス設定と視聴回数を確認します。

---

### `!visits @<ユーザー名>`
指定した他ユーザーの視聴回数を確認します（自分の確認は権限不要）。

---

## 待機列管理コマンド（`!queue`）

参加者の待機列を一元管理するコマンドです。サブコマンド形式で統一されています。

### `!queue remove <ユーザー名>`
待機リストから指定ユーザーを削除します。

```
!queue remove username
!queue remove @username
→ @username を参加者リストから削除しました
```

### `!queue clear`
待機リストを全件クリアします。

```
!queue clear
→ 参加者リストをクリアしました（5人）
```

### `!queue next`
待機者全員を「参加済み」に移動し、待機リストをクリアします。次のラウンドを開始するときに使います。

```
!queue next
→ ラウンド開始: 5人を参加済みに移動しました（累計参加済み: 10人）
```

### `!queue reset`
参加済みセットをリセットし、全員が再度参加登録できる状態に戻します。

```
!queue reset
→ ラウンドリセット: 10人が再参加可能になりました
```

### `!queue played <ユーザー名>`
指定ユーザーを「参加済み」にマークし、待機リストから除去します。

```
!queue played username
→ @username を参加済みにしました（参加済み累計: 3人）
```

> **後方互換**: `!remove`、`!clearall`、`!nextround`、`!roundreset`、`!played` は引き続き使用できます。

## 配信情報コマンド（`!stream`） — Twitch限定

配信タイトルやゲームカテゴリをチャットから変更できます。`channel:manage:broadcast` スコープが必要です（再認証が必要な場合があります）。

### `!stream title <タイトル>`
配信タイトルを変更します。

```
!stream title 今日もまったり雑談枠！
→ 配信タイトルを変更しました: 今日もまったり雑談枠！
```

### `!stream game <ゲーム名>`
ゲームカテゴリを変更します。Twitchで検索して最も近いカテゴリが自動選択されます。

```
!stream game マリオカート8
→ ゲームカテゴリを変更しました: Mario Kart 8 Deluxe
```

---

## 参加登録キーワード（コマンド以外）

以下のキーワードを含むチャットで待機リストに**自動登録**されます（設定パネルで変更可能）。

| キーワード | 動作 |
|-----------|------|
| `参加希望` | 待機リストに自動追加 |
| `参加` | 待機リストに自動追加 |
| `!参加` | 待機リストに自動追加 |
| `!join` | 待機リストに自動追加 |

---

## カスタムコマンド

GUIの「コマンド」パネルから独自コマンドを追加できます。

| 設定項目 | 説明 |
|---------|------|
| コマンド名 | `!` を除いた名前（例: `hello`） |
| 応答テンプレート | チャットに送信するテキスト |
| 権限レベル | 0〜4（上記の権限レベル参照） |
| グローバルCT | 全ユーザー共通のクールダウン（秒） |
| ユーザーCT | 個人単位のクールダウン（秒） |
| 有効/無効 | コマンドを一時的に無効化できる |

### 応答テンプレート変数

| 変数 | 展開内容 |
|-----|---------|
| `{user}` | コマンド実行者の表示名 |
| `{channel}` | チャンネル名 |
| `{time}` | 現在時刻（HH:MM） |
| `{date}` | 現在日付（YYYY/MM/DD） |
