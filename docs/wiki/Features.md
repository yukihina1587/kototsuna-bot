# 機能一覧

## チャット翻訳

### 自動翻訳

Twitchチャットのメッセージを自動的に翻訳します。

- **翻訳モード**:
  - 自動: 日本語→英語、その他→日本語
  - 英→日: 英語を日本語に翻訳
  - 日→英: 日本語を英語に翻訳

### 翻訳フィルター

特定のワードを含むメッセージの翻訳をスキップします。

- 設定パネルの「辞書」タブで設定
- 部分一致で判定

### カスタム辞書

翻訳前にテキストを置換します。

- 固有名詞の翻訳を制御
- 例: `YAGOO` → `谷郷`

## 音声機能

### チャット読み上げ（TTS）

日本語のチャットメッセージを音声で読み上げます。

| エンジン | 品質 | 必要なもの |
|---------|------|-----------|
| VOICEVOX | 高 | VOICEVOX Engine |
| pyttsx3 | 低 | なし（フォールバック） |

**ボイス選択**: 設定パネルで複数のボイスから選択可能

### 読み上げ辞書

漢字の読み間違いを修正します。

- 例: `草` → `くさ`（「そう」ではなく）
- 設定パネルの「辞書」タブで設定

### 音声翻訳（マイク入力）

マイクに向かって喋った内容を翻訳します。

| プロバイダ | 品質 | 制限 |
|-----------|------|------|
| Gladia API | 高 | 月10時間（無料枠） |
| Google SR | 中 | 制限なし（フォールバック） |

## Twitchイベント検知

### 対応イベント

| イベント | 検知方法 | 効果音 |
|---------|---------|--------|
| フォロー | EventSub WebSocket | ✅ |
| サブスク | IRC usernotice | ✅ |
| ギフトサブ | IRC usernotice | ✅ |
| Bits | IRC usernotice | ✅ |

### イベント効果音

各イベントに個別の効果音を設定できます。

- 対応形式: MP3, WAV, OGG
- 個別のボリューム調整
- 左サイドバーでテスト再生

## 参加者追跡

特定のキーワードを含むメッセージを送信したユーザーを追跡します。

- キーワード設定可能（例: `参加`, `join`）
- 参加者リストをチャットに送出可能
- 設定パネルの「参加者」タブで管理
- 参加者数上限: デフォルト1000人（`config.json`の`participant_limit`で変更可能）

## チャットコマンド

Twitchチャットで `!` プレフィックスのコマンドを使用できます。

### ビルトインコマンド

| コマンド | 権限 | 説明 |
|---------|------|------|
| `!help` | 全員 | 使用可能なコマンド一覧を表示 |
| `!translate <テキスト>` | 全員 | テキストを翻訳して返信 |
| `!lang` | 全員 | 現在の翻訳モードを表示 |
| `!tts on/off` | モデレーター | TTS読み上げの有効/無効を切替 |
| `!voice` | モデレーター | 利用可能なVOICEVOXボイス一覧 |

### カスタムコマンド

GUIの「コマンド」パネルからカスタムコマンドを追加できます。

- コマンド名・応答テンプレート・権限レベル・クールダウンを設定
- `custom_commands.json` に保存
- 応答テンプレートで使用できる変数:
  - `{user}` — コマンド実行者の表示名
  - `{channel}` — チャンネル名
  - `{time}` — 現在時刻（HH:MM）
  - `{date}` — 現在日付（YYYY/MM/DD）

### 権限レベル

| レベル | 値 | 説明 |
|-------|---|------|
| 全員 | 0 | すべてのユーザー |
| サブスク | 1 | サブスクライバー |
| VIP | 2 | VIPユーザー |
| モデレーター | 3 | チャンネルモデレーター |
| 配信者 | 4 | チャンネルオーナー |

上位権限は下位権限を包含します（例: モデレーターはサブスク・VIPコマンドも使用可能）。

### クールダウン

各コマンドにグローバル（全ユーザー共通）とユーザー個別のクールダウンを設定できます。クールダウン中のコマンドは無視されます。

## パフォーマンス最適化

### メモリ管理

長時間稼働でのメモリリークを防止する仕組みが組み込まれています。

| 項目 | 制限 | 設定キー |
|-----|------|---------|
| ログ履歴 | 最大1000件 | `chat_log_history_limit` |
| チャット履歴 | 最大200件 | （固定） |
| 参加者リスト | 最大1000人 | `participant_limit` |

### 翻訳バッチ処理

チャットメッセージの翻訳を効率化します。

- 100ms間のメッセージをまとめてAPI呼び出し（最大5件）
- キャッシュ済みテキストは即座に返却
- aiohttpセッションの永続化で接続オーバーヘッドを削減

### GUI差分更新

参加者リストなどのUI更新を最適化します。

- 変更があった部分だけウィジェットを操作
- 3秒ごとの全destroy→全再作成パターンを廃止

### リソース監視

アプリケーションのリソース使用状況をリアルタイムで監視します。

- メモリ使用量（MB / %）
- CPU使用率（プロセス / システム）
- アクティブスレッド数
- メモリ閾値超過時の自動再起動オプション

### パフォーマンス計測

翻訳APIの応答時間を統計表示します。

- リクエスト数、キャッシュヒット率
- 平均応答時間（ms）
- P95/P99パーセンタイル（サンプル20件以上時）

### プロファイリング

```bash
python scripts/profile_app.py cpu      # CPUプロファイリング
python scripts/profile_app.py memory   # メモリプロファイリングガイド
```

## ログ機能

### ログファイル

- 場所: `dist/logs/bot_YYYY-MM-DD.log`
- 日付ごとにローテーション
- 7日間保持

### ログレベル

GUIから動的に変更可能:

- DEBUG: 詳細なデバッグ情報
- INFO: 通常の動作情報
- WARNING: 警告
- ERROR: エラーのみ
