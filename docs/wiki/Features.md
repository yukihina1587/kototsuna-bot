# 機能一覧

## チャット翻訳

### 自動翻訳

Twitchチャットのメッセージを自動的に翻訳します。

- **翻訳モード**:
  - 自動: 日本語→英語、その他→日本語
  - 英→日: 英語を日本語に翻訳
  - 日→英: 日本語を英語に翻訳

### 翻訳フィルター

特定のワードを含むメッセージの翻訳をスキップします。

- 設定パネルの「辞書」タブで設定
- 部分一致で判定

### カスタム辞書

翻訳前にテキストを置換します。

- 固有名詞の翻訳を制御
- 例: `YAGOO` → `谷郷`

## 音声機能

### チャット読み上げ（TTS）

日本語のチャットメッセージを音声で読み上げます。

| エンジン | 品質 | 必要なもの |
|---------|------|-----------|
| VOICEVOX | 高 | VOICEVOX Engine |
| pyttsx3 | 低 | なし（フォールバック） |

**ボイス選択**: 設定パネルで複数のボイスから選択可能

### 読み上げ辞書

漢字の読み間違いを修正します。

- 例: `草` → `くさ`（「そう」ではなく）
- 設定パネルの「辞書」タブで設定

### 音声翻訳（マイク入力）

マイクに向かって喋った内容を翻訳します。

| プロバイダ | 品質 | 制限 |
|-----------|------|------|
| ReazonSpeech-k2-v2 | 高 | ローカル実行 |

## Twitchイベント検知

### 対応イベント

| イベント | 検知方法 | 効果音 |
|---------|---------|--------|
| フォロー | EventSub WebSocket | ✅ |
| サブスク | IRC usernotice | ✅ |
| ギフトサブ | IRC usernotice | ✅ |
| Bits | IRC usernotice | ✅ |

### イベント効果音

各イベントに個別の効果音を設定できます。

- 対応形式: MP3, WAV, OGG
- 個別のボリューム調整
- 左サイドバーでテスト再生

## 参加者追跡

特定のキーワードを含むメッセージを送信したユーザーを追跡します。

- キーワード設定可能（例: `参加`, `!join`）
- 参加者リストをチャットに送出可能
- 設定パネルの「参加者」タブで管理
- 参加者数上限: デフォルト1000人（`config.json`の`participant_limit`で変更可能）
- モデレーターは `!queue` コマンドで待機列を直接操作可能

## チャットコマンド

Twitchチャットで `!` プレフィックスのコマンドを使用できます。詳細は [コマンドリファレンス](Commands) を参照してください。

### 全ユーザー向けコマンド

| コマンド | 説明 |
|---------|------|
| `!help` | 使用可能なコマンド一覧を表示 |
| `!translate <テキスト>` | テキストを翻訳して返信 |
| `!lang` | 現在の翻訳モードを表示 |
| `!visits` | 自分の視聴回数を確認 |
| `!leave` | 自分を待機リストから退出 |
| `!voice list` | 利用可能なVOICEVOXボイス一覧 |
| `!myvoice` | 自分のボイスを確認 |
| `!myvoice <ID>` | 自分のボイスを設定（self_serviceモード時またはMOD+） |
| `!myvoice reset` | ボイスをデフォルトに戻す |

### モデレーター以上向けコマンド

| コマンド | 説明 |
|---------|------|
| `!tts on/off` | TTS読み上げの有効/無効を切替 |
| `!translation on/off` | チャット翻訳の有効/無効を切替 |
| `!voicechat on/off` | 声→翻訳チャットの有効/無効を切替 |
| `!dict add <単語> <読み>` | TTS辞書に単語を追加 |
| `!dict list` | TTS辞書の登録一覧を表示 |
| `!dict remove <単語>` | TTS辞書から単語を削除 |
| `!voice set @user <ID>` | ユーザーにボイスを割り当て |
| `!voice remove @user` | ユーザーのボイス割り当てを解除 |
| `!voice check @user` | ユーザーのボイスを確認 |
| `!visits @user` | 他ユーザーの視聴回数を確認 |
| `!queue remove <user>` | 待機リストから指定ユーザーを削除 |
| `!queue clear` | 待機リストを全件クリア |
| `!queue next` | 待機者全員を参加済みに移動してリストをクリア |
| `!queue reset` | 参加済みセットをリセット（全員が再参加可能に） |
| `!queue played <user>` | 指定ユーザーを参加済みにマーク |
| `!stream title <タイトル>` | 配信タイトルを変更（Twitch限定） |
| `!stream game <ゲーム名>` | ゲームカテゴリを変更（Twitch限定） |

### カスタムコマンド

GUIの「コマンド」パネルからカスタムコマンドを追加できます。

- コマンド名・応答テンプレート・権限レベル・クールダウンを設定
- `custom_commands.json` に保存
- 応答テンプレートで使用できる変数:
  - `{user}` — コマンド実行者の表示名
  - `{channel}` — チャンネル名
  - `{time}` — 現在時刻（HH:MM）
  - `{date}` — 現在日付（YYYY/MM/DD）

### 権限レベル

| レベル | 値 | 説明 |
|-------|---|------|
| 全員 | 0 | すべてのユーザー |
| サブスク | 1 | サブスクライバー |
| VIP | 2 | VIPユーザー |
| モデレーター | 3 | チャンネルモデレーター |
| 配信者 | 4 | チャンネルオーナー |

上位権限は下位権限を包含します（例: モデレーターはサブスク・VIPコマンドも使用可能）。

### クールダウン

各コマンドにグローバル（全ユーザー共通）とユーザー個別のクールダウンを設定できます。クールダウン中のコマンドは無視されます。

### 参加登録キーワード

コマンド以外に、以下のキーワードを含むチャットで待機リストに自動登録されます（設定で変更可能）。

| キーワード | 動作 |
|-----------|------|
| `参加希望` / `参加` | 待機リストに自動追加 |
| `!参加` / `!join` | 待機リストに自動追加 |

## パフォーマンス最適化

### メモリ管理

長時間稼働でのメモリリークを防止する仕組みが組み込まれています。

| 項目 | 制限 | 設定キー |
|-----|------|---------|
| ログ履歴 | 最大1000件 | `chat_log_history_limit` |
| チャット履歴 | 最大200件 | （固定） |
| 参加者リスト | 最大1000人 | `participant_limit` |

### 翻訳バッチ処理

チャットメッセージの翻訳を効率化します。

- 100ms間のメッセージをまとめてAPI呼び出し（最大5件）
- キャッシュ済みテキストは即座に返却
- aiohttpセッションの永続化で接続オーバーヘッドを削減

### GUI差分更新

参加者リストなどのUI更新を最適化します。

- 変更があった部分だけウィジェットを操作
- 3秒ごとの全destroy→全再作成パターンを廃止

### リソース監視

アプリケーションのリソース使用状況をリアルタイムで監視します。

- メモリ使用量（MB / %）
- CPU使用率（プロセス / システム）
- アクティブスレッド数
- メモリ閾値超過時の自動再起動オプション

### パフォーマンス計測

翻訳APIの応答時間を統計表示します。

- リクエスト数、キャッシュヒット率
- 平均応答時間（ms）
- P95/P99パーセンタイル（サンプル20件以上時）

### プロファイリング

```bash
python scripts/profile_app.py cpu      # CPUプロファイリング
python scripts/profile_app.py memory   # メモリプロファイリングガイド
```

## ログ機能

### ログファイル

- 場所: `dist/logs/bot_YYYY-MM-DD.log`
- 日付ごとにローテーション
- 7日間保持

### ログレベル

GUIから動的に変更可能:

- DEBUG: 詳細なデバッグ情報
- INFO: 通常の動作情報
- WARNING: 警告
- ERROR: エラーのみ
