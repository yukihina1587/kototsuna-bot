    GET STARTED

    配信を始めるまで

    1. 設定からTwitchに接続

      「設定・Twitch接続」でチャンネルを指定して保存し、Twitchに接続します。認証時だけブラウザが開きます。

    2. BOTを開始して、翻訳をON

      読み上げ音量や速度はこの画面から変更できます。マイクや声は「設定」の音声タブで選べます。

    3. OBSにコメントを表示

      「コメント表示URL」をOBSのブラウザソースに貼り付けます。

    4. OBSの中でも操作

      「操作パネルURL」をOBSのカスタムブラウザドックに追加します。このURLは自分のPCで、ことつな本体を起動している間だけ使えます。共有しないでください。

    アプリのウィンドウを閉じるとBOTと音声処理も終了します。配信中は最小化してください。OBSの操作ドックを閉じてもアプリは動き続けます。
